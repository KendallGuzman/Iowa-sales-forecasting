# Iowa Store Purchasing Analysis & Forecasting

## Business objective
Analyze store purchasing patterns and develop forecasts
to support distributor inventory and sales planning.

## Tools
Python, pandas, PostgreSQL through Supabase, and Git.

## Data source
Iowa Department of Revenue — Iowa Liquor Sales, 2024.
https://data.iowa.gov/catalog/dataset/1261

The records describe purchases by licensed stores,
rather than individual shoppers' checkout purchases.

## Progress
- Downloaded and extracted five CSV files.
- Inspected five rows from the first file.
- Calculated the recorded dollar amount per bottle.
- Checked data types and converted the order date.

## Initial observations
Both state bottle price columns are entirely missing
in the five-row sample. Full-dataset checks are pending.
